Where would ROI Advisor live?

Based on what was tested live today. Green = inside graph8 (native), blue = our small external engine.

Inside graph8 (what the user sees)
① ROI dashboard = an App Page
graph8 hosts it in-app (sandboxed frame, editable by chat). It reads a custom object or Workbench table, the only two source types available today, which is where our engine writes the numbers.
⚠ Generating the page uses graph8's AI, which is down today; needs a retest.
② Pre-spend advisor = native guardrails
graph8 has no plug-in slot in its Enrich dialog. Instead we write an "ROI fit" field per contact, and graph8's own list-routing rules, enrichment run conditions and qualify-first pipelines skip low-ROI records automatically. The advice gets enforced, with no pop-up.
③ Weekly recap = a graph8 workflow
Scheduled trigger → pull findings (Workbench rows or our MCP tool) → Slack / email nodes. All native node types.
④ Ask it anything = our engine registered as an MCP server
Orgs can register custom MCP servers, so graph8 workflows and agents can call "cost per meeting for fintech VPs?" as a tool.
⇄
External ROI engine (small service)

Needed because graph8's hosted app runtime doesn't exist yet (its own API says so).

  1. Collect spend: credit ledger + job and run records (captured as they happen)
  2. Collect outcomes: webhooks (deals ✔ tested live), engagement summaries per contact, analytics
  3. Attribute: charge → run → contact → list / segment / step / channel
  4. Compute: cost per meeting / deal; waste; findings with confidence
  5. Write back to graph8: custom object (dashboard), ROI-fit field (guardrails), Workbench (recap)
